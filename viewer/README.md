# viewer

Quest 3 Browser 向けの WebXR ビューア。editor が書き出した SBS 正距円筒 180° の写真（2N×N、左半分が左目、右半分が右目）を立体表示する。

## 使い方

```
pnpm install
pnpm dev
```

表示する写真の URL を `?photo=` で指定する（ギャラリー #39 ができるまでの暫定）。

```
https://<host>:8443/?photo=/photos/20260101-090000-000_180_LR.jpg
```

WebXR に対応したブラウザでは「VR で見る」ボタンから immersive-vr で表示する。

## 立体表示のしくみ

- 左目用と右目用に 180°×180° の半球メッシュを 2 つ作り、正面（-Z）を中心に内側から見る。左目のメッシュは SBS 画像の左半分（u 0–0.5）、右目は右半分（u 0.5–1）を貼る。
- 左目のメッシュはレイヤ 1、右目はレイヤ 2 にだけ置く。three.js の WebXR では左目のカメラがレイヤ 1、右目のカメラがレイヤ 2 を描画するため、それぞれの目には自分用の半球だけが見える。
- XR でないときのプレビューは左目（レイヤ 1）を表示する。
- 参照空間は `local` を使い、視点を半球の中心に置く。
