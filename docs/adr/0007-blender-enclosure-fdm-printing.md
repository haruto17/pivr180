# 0007. 筐体は Blender で設計し、Bambu Lab A1 で FDM 印刷する

## ステータス

承認

## コンテキスト

pivr180 の筐体には、カメラ・Pi・NVMe・バッテリーの固定と、以下の光学要件が求められる（[plan.md](../plan.md)）。

- レンズ間隔 64mm
- 光軸が平行
- レンズ面より前に筐体を出さない（190° の視野に入らないように）
- 1/4" 三脚穴

寸法精度が必要な内部構造と、見た目を整えたい外観の両方を扱える設計手段と、製造手段を決める必要がある。印刷機は Bambu Lab A1（FDM, 256mm 角）を使える。

## 決定

- 筐体は **Blender** で設計する。
  - 寸法が重要な内部構造（カメラ・Pi・NVMe・バッテリーの固定、レンズ間隔）は **bpy スクリプトでパラメトリック生成**し、STL/3MF を出力する。
  - 外観は手作業モデリングで仕上げる。
- **Bambu Lab A1** で FDM 印刷する。

## 検討した選択肢

### CadQuery

- 利点: コードによるパラメトリック CAD で、寸法管理に強い。
- 欠点: 有機的な外観の造形には向かない。

### Fusion 360・FreeCAD

- 利点: 機械設計向けのパラメトリック CAD で、寸法拘束を扱いやすい。
- 欠点: 設計データのコード管理（差分レビュー）がしにくい。外観の自由な造形は Blender に劣る。

### 全手作業（Blender）

- 利点: 外観の自由度が最も高い。
- 欠点: レンズ間隔などの重要寸法を手作業で維持する必要があり、変更に弱い。

### Blender（寸法重要部は bpy でパラメトリック生成、外観は手作業）（採用）

- 利点: 重要寸法をスクリプトで再現性高く管理しつつ、外観の自由な造形と両立できる。スクリプトを `hardware/` で git 管理できる。
- 欠点: パラメトリック生成部と手作業部の境界の管理が必要。

## 結果 / 影響

- 重要寸法をスクリプトで再生成でき、部品やパラメータの変更に追従しやすい。
- bpy スクリプトと STL/3MF は `hardware/` に置く。
- 手作業の外観部は再生成されないため、内部構造を変更した際に外観との整合を取り直すコストを受け入れる。
- FDM 印刷の寸法誤差がリスクとなる。パラメータで調整し、試し印刷で確認する。
