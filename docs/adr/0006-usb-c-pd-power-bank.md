# 0006. 電源は USB-C PD モバイルバッテリーとする

## ステータス

承認

## コンテキスト

pivr180 は持ち歩き可能なカメラであり、Raspberry Pi 5、HQ Camera ×2、NVMe SSD をバッテリーで駆動する必要がある（[plan.md](../plan.md)、[device_specs.md](../device_specs.md)）。

Raspberry Pi 5 は 5V/5A の USB-C 給電に対応しない電源では USB 給電が制限される。電源方式と、それを筐体にどう収めるかを決める必要がある。

## 決定

- 電源は **USB-C PD モバイルバッテリー**とする。
- バッテリーは筐体に固定し、交換可能にする。
- 5V/5A 非対応時の USB 給電制限は検証項目とする。NVMe は PCIe 接続のため、この制限の影響を受けない。

## 検討した選択肢

### 18650 UPS HAT

- 利点: Pi と一体化でき、コンパクトにまとめやすい。
- 欠点: セルの調達・管理が必要で、容量や出力が HAT の仕様に縛られる。

### LiPo 自作

- 利点: 形状・容量を筐体に合わせて最適化できる。
- 欠点: 保護回路・充電回路の設計が必要で、安全面のリスクが高い。

### USB-C PD モバイルバッテリー（採用）

- 利点: 市販品で入手・交換が容易で、充電回路や保護回路を自作する必要がない。
- 欠点: 5V/5A に対応しない製品が多く、USB 給電が制限される可能性がある。筐体内でのサイズが大きくなりやすい。

## 結果 / 影響

- 安全で入手しやすい電源を、交換可能な形で採用できる。
- 筐体はバッテリーを固定・交換できる構造にする必要がある（[0007](./0007-blender-enclosure-fdm-printing.md)）。
- 5V/5A 非対応による USB 給電制限がリスクとなる。NVMe は PCIe のため影響しないが、USB 給電への影響を実機で検証する。
