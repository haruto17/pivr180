# Pi と AtomS3 Lite の通信

Pi と AtomS3 Lite は USB シリアル（CDC）で、1 行 1 メッセージのテキストをやりとりする（[ADR 0008](../docs/adr/0008-atoms3-lite-usb-shutter-and-status.md)）。

## 共通の取り決め

- メッセージは ASCII のテキストで、1 行に 1 つ送る。行は `\n`（LF）で終える。
- 受信側は、行末の `\r` を取り除いてから解釈する。
- 受信側は、知らないメッセージの行を無視する。
- ボーレートは 115200 を指定する。ただし USB CDC なので、実際の通信速度には影響しない。

## AtomS3 Lite → Pi

ボタン（GPIO41）の押下と解放を送る。長押しの判定は Pi 側で行う。

| メッセージ | 意味 |
|---|---|
| `press` | ボタンが押された |
| `release` | ボタンが離された |

- ボタンの状態が 20ms 続いたときに確定し、変化したときに 1 回だけ送る。チャタリングによる短い変化は送らない。
- 起動直後は、ボタンが離されている状態から始める。そのため `press` と `release` は必ず交互に送られ、最初に送られるのは `press` になる。
- 起動時にボタンを押したままの場合は、起動後すぐに `press` を送る。
- メッセージに時刻は含めない。長押しの時間は、Pi が受信した時刻で測る。

例（ボタンを押して離した場合）:

```
press
release
```

## Pi → AtomS3 Lite

Pi は現在の状態を 1 秒ごとに送り直す。これをハートビートとする。

| メッセージ | 状態 |
|---|---|
| `idle` | 待機中 |
| `capturing` | 撮影中 |
| `error` | エラー |

- メッセージは完全一致で判定する（大文字・小文字を区別し、前後の空白も許さない）。それ以外の行は無視し、ハートビートとしても数えない。
- 32 文字を超える行は捨てる。
- 最後に有効なメッセージを受け取ってから **3 秒**（3000 ms）経つと、切断の表示にする。Pi が送り直すのを 2 回続けて取りこぼしても、切断と判定しないため。メッセージが再び届けば、その状態の表示に戻る。

### LED の表示

状態は色と点滅の両方で区別する。眩しくならないよう、明るさは最大の 1/8 程度に抑えている。

| 状態 | 色 | 点滅 |
|---|---|---|
| 起動中（最初のメッセージを受け取るまで） | 白 | ゆっくり点滅（0.5 秒点灯・0.5 秒消灯） |
| 待機中 | 緑 | 点灯 |
| 撮影中 | 青 | 点灯 |
| エラー | 赤 | 速く点滅（0.15 秒点灯・0.15 秒消灯） |
| 切断 | 橙 | 短く光る（0.1 秒点灯・1.9 秒消灯） |
