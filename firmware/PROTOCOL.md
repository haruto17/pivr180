# Pi と AtomS3 Lite の通信

Pi と AtomS3 Lite は USB シリアル（CDC）で、1 行 1 メッセージのテキストをやりとりする（[ADR 0008](../docs/adr/0008-atoms3-lite-usb-shutter-and-status.md)）。

## 共通の取り決め

- メッセージは ASCII のテキストで、1 行に 1 つ送る。行は `\n`（LF）で終える。
- 受信側は、行末の `\r` を取り除いてから解釈する。
- 受信側は、知らないメッセージの行を無視する。
- ボーレートは 115200 を指定する。ただし USB CDC なので、実際の通信速度には影響しない。

## AtomS3 Lite → Pi

ボタン（GPIO41）の押下と解放を送る。長押しの判定は Pi 側で行う。

| メッセージ | 意味 |
|---|---|
| `press` | ボタンが押された |
| `release` | ボタンが離された |

- ボタンの状態が 20ms 続いたときに確定し、変化したときに 1 回だけ送る。チャタリングによる短い変化は送らない。
- 起動直後は、ボタンが離されている状態から始める。そのため `press` と `release` は必ず交互に送られ、最初に送られるのは `press` になる。
- 起動時にボタンを押したままの場合は、起動後すぐに `press` を送る。
- メッセージに時刻は含めない。長押しの時間は、Pi が受信した時刻で測る。

例（ボタンを押して離した場合）:

```
press
release
```
