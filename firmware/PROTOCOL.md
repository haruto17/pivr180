# Pi と AtomS3 Lite の通信

Pi と AtomS3 Lite は USB シリアル（CDC）でつなぐ。メッセージは ASCII テキストで、1 行に 1 つ送る。行末は `\n` で、直前の `\r` は無視する。知らないメッセージの行は無視する。

## Pi → AtomS3 Lite

Pi は現在の状態を 1 秒ごとに送り直す。これをハートビートとする。

| メッセージ | 状態 |
|---|---|
| `idle` | 待機中 |
| `capturing` | 撮影中 |
| `error` | エラー |

- メッセージは完全一致で判定する（大文字・小文字を区別し、前後の空白も許さない）。それ以外の行は無視し、ハートビートとしても数えない。
- 32 文字を超える行は捨てる。
- 最後に有効なメッセージを受け取ってから **3 秒**（3000 ms）経つと、切断の表示にする。Pi が送り直すのを 2 回続けて取りこぼしても、切断と判定しないため。メッセージが再び届けば、その状態の表示に戻る。

### LED の表示

状態は色と点滅の両方で区別する。眩しくならないよう、明るさは最大の 1/8 程度に抑えている。

| 状態 | 色 | 点滅 |
|---|---|---|
| 起動中（最初のメッセージを受け取るまで） | 白 | ゆっくり点滅（0.5 秒点灯・0.5 秒消灯） |
| 待機中 | 緑 | 点灯 |
| 撮影中 | 青 | 点灯 |
| エラー | 赤 | 速く点滅（0.15 秒点灯・0.15 秒消灯） |
| 切断 | 橙 | 短く光る（0.1 秒点灯・1.9 秒消灯） |
